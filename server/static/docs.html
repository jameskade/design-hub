Design Hub Read API

供本机或局域网 AI Agent 读取项目、设计稿布局和资源。实现页面时优先读取结构化数据，不需要通过截图推断布局。

OpenAPI 3.1 · llms.txt · 服务发现

认证

Authorization: Bearer dhk_xxx

在 Design Hub 登录后点击“AI API Key”创建。Key 绑定创建用户、实时继承项目权限且只允许读取。不要把 Key 放进 URL。

推荐流程

顺序接口用途
1GET /api/me验证 Key 与用户身份
2GET /api/projects列出有权限项目
3GET /api/projects/{id}/artboards查找设计稿 ID
4GET /api/artboards/{id}/ai-context读取无需截图的布局上下文
5GET /api/assets/{id}/download下载图片和图标

调用示例

curl -H "Authorization: Bearer $DESIGN_HUB_API_KEY" \
  "$DESIGN_HUB_URL/api/artboards/<artboard_id>/ai-context"

分享设计稿链接

把普通设计稿页面交给 AI 时，页面的 service-desc 会指向 OpenAPI，alternate 会指向当前画板的 ai-context。也可以使用：

/ai/artboards/{artboard_id}

该自描述入口公开返回接口位置和认证方式，但不会公开任何设计数据。
