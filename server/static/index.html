给设计师

让好设计，顺利抵达。

选中画板，一次同步。让团队直接查看最新设计、精确标注和配套资源。

  1. 1

    下载并安装插件

    解压下载的 ZIP，双击 DesignHub.sketchplugin，按 Sketch 提示安装。插件位于「插件 → Design Hub」。

    需要 macOS 与 Sketch。已有旧版时按 Sketch 的提示更新，然后重新打开 Sketch。

  2. 2

    连接团队的 Design Hub

    在「插件 → Design Hub → 配置服务地址」粘贴上方地址。首次上传时，使用本站账号登录。

    还没有账号？先在登录页申请注册，由管理员分配身份，再由项目负责人添加项目权限。

  3. 3

    选中画板，上传到项目

    在 Sketch 里选中要交付的画板，运行「上传选中画板」，选择项目与目录，等待实际上传结果。

    同步范围由你的选择决定

    同一个画板有变化时生成新版本；未变化的跳过。没有选中的画板不会被删除或覆盖。

给开发者与 AI

让 AI 读到设计的细节。

通过 MCP 获取图层、文字、样式与真实资源，给实现提供结构化依据。

  1. 1

    确认电脑可运行 npx

    需要 Node.js 18+（含 npm/npx）。客户端会从本站自动下载安装包，不需要 Python、手动下载脚本或访问公共 npm 仓库。已有 Python 配置也可以继续使用。

    旧版 Python 接入
  2. 2

    复制客户端配置

    默认使用服务器地址下载并启动本地 MCP，服务 IP 可修改；网站地址不是远程 MCP 端点。

    填写这台电脑的脚本绝对路径，不使用 ~ 缩写。

    首次启动需连接服务器下载；升级时重新复制新版本配置。其他同事应填写服务器局域网 IP 或域名，不使用 localhost。若客户端找不到 npx，请填写其绝对路径；Windows 可使用 npx.cmd。

    填写脚本路径后即可复制配置。

    ~/.codex/config.toml
    填写上方路径，生成此电脑可用的配置。

    合并到已有配置中，保留其他服务条目。保存后，在客户端重新加载 MCP 或重新打开客户端。

    查看 Codex 官方配置说明 ↗
  3. 3

    填写个人 Key，验证实际调用

    在「你的个人访问凭据」中创建只读 Key，在自己的客户端配置中替换 DESIGN_HUB_API_KEY 占位符；npx 模式无需每次调用重复提供地址和 Key。Python 模式仍通过工具参数提供。不要分享包含真实 Key 的配置。

    列出可见项目design_hub_list_projects读取设计上下文design_hub_get_artboard_context读取图片资源design_hub_get_asset

    以 AI 客户端的真实调用结果为准。网页不能判断另一台电脑是否已连接。

遇到问题时

插件里没有项目，或无法上传

先用相同账号登录工作台，确认身份已审核且具有项目编辑权限。再核对插件配置的服务地址；其他电脑不能使用服务器的 127.0.0.1 地址。

MCP 启动失败，或找不到 Python / 脚本

确认 Python 安装在运行 AI 客户端的电脑上，配置中的脚本与解释器路径确实存在。脚本通过标准输入输出通信，直接在终端运行后等待输入是正常现象。

MCP 返回 401、403 或空列表

401 通常需要检查 Key 是否正确或已撤销；403 需要检查账号身份或项目权限；空列表表示当前账号没有可见项目。请通过本站 Key 管理和项目负责人处理。

缺少无阴影资源，或预览没有更新

先确认查看的是需要的设计版本。缺少无阴影资源时，请设计师用当前插件重新同步画板；页面不会用裁剪来冒充去掉阴影。
